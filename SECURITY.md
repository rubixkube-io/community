# Security

Please **don't report security problems in public issues or discussions.**

Report them privately instead:

- Email [security@rubixkube.ai](mailto:security@rubixkube.ai), or
- use [Report a vulnerability](https://github.com/rubixkube-io/community/security/advisories/new) on this repository.

Please include what's affected (RubixKube or Kepler, and which part), the version, steps to reproduce, and what an attacker could do. We aim to acknowledge reports within 24 hours, and we'll keep you updated until it's fixed.
