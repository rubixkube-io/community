# RubixKube Community

The public place to report bugs and share feedback on **RubixKube** and **Kepler**.

| I want to… | Go to |
| --- | --- |
| Report a bug | [New issue](https://github.com/rubixkube-io/community/issues/new/choose) |
| Suggest a feature or share feedback | [Discussions → Ideas](https://github.com/rubixkube-io/community/discussions/categories/ideas) |
| Ask how to do something | [Discussions → Q&A](https://github.com/rubixkube-io/community/discussions/categories/q-a) |
| Chat about Kepler | [Kepler Discord](https://discord.gg/nRcFFrn2M) |
| Chat about RubixKube | [RubixKube Slack](https://join.slack.com/t/rubixkubecommunity/shared_invite/zt-3fq7kiu8k-RC5uzLY6BjQFE5Uq_NziEA) |
| Report a security problem | Email [security@rubixkube.ai](mailto:security@rubixkube.ai). Please don't open a public issue. See [SECURITY.md](SECURITY.md). |
| Get help with your account or data | Email [support@rubixkube.ai](mailto:support@rubixkube.ai) |

Before you post, please search [existing issues](https://github.com/rubixkube-io/community/issues) and [discussions](https://github.com/rubixkube-io/community/discussions). Adding a 👍 to one that already exists helps us see what matters most.

Issues and discussions here are public. Don't paste secrets, tokens, customer data or anything from your logs you wouldn't want others to see.
